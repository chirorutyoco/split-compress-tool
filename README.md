# ココフォリア用 分割圧縮ツール

大きな画像を、ココフォリアの制限(1枚あたり 1280×720px 以内・1MB 未満)に収まるタイルに分割する Windows 用ツールです。元の解像度を保ったまま、継ぎ目なく並べられます。

## ダウンロード
[Releases](../../releases/latest) から `Divide.and.conquer.exe` をダウンロードしてください。

## 使い方
1. exe を起動する。
2. 画像をドラッグ&ドロップする。
3. 「分割を実行」を押す。

exe と同じ場所の `output` フォルダにタイルが出力されます。

## 機能
- 静止画(PNG / JPG / WebP / BMP)とアニメーション(APNG / WebP)に対応
- 1MB を超える場合は、分割数を自動で調整
- 分割前のリサイズに対応
- 配置時の移動量(マス数)を実行結果に表示

## 注意
- 目的は画質の維持です。タイルの合計容量は元画像より増えることがあります。
- 署名のない exe のため、Windows の警告が出ることがあります。
- 他の人の素材を使う場合は、配布元の利用規約を確認してください。
- ほぼ生じえないですが、データ破損など何かしらの問題が生じた場合にも責任は取りかねます。
